# Contribuir a ClassNote

Gracias por ayudar a crear una herramienta útil para docentes.

## Antes de empezar
- Lee `AGENTS.md`, `MVP.md`, `ARCHITECTURE.md` y `SECURITY.md`.
- Elige una tarea de `TASKS.md` y propone un cambio pequeño.
- Para cambios de persistencia, adjunta estrategia de migración y pruebas con datos ficticios.

## Flujo Git
Ramas: `feat/CN-006-attendance`, `fix/CN-012-restore`, `docs/...`.
Commits estilo Conventional Commits: `feat: ...`, `fix: ...`, `test: ...`, `docs: ...`.

## Pull request
Indica problema, alcance, capturas sin alumnos reales, pruebas realizadas, impacto sobre datos, permisos Tauri añadidos y migraciones. No subir binarios, perfiles, backups reales ni información sensible.

## Código de conducta
Trato respetuoso, discusión centrada en hechos y colaboración. Se puede añadir un `CODE_OF_CONDUCT.md` formal antes de apertura a comunidad.

## Licencia
Pendiente de seleccionar explícitamente. No asumir licencia por defecto si no existe archivo `LICENSE`.
